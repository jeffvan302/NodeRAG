# NodeRag Test Fixtures

This directory contains small, non-private, synthetic files used by automated
tests. It must never contain production documents or copies of private source
material. Every binary fixture is listed in `formats/fixture-catalog.json` with
its purpose, provenance, expected disposition, and SHA-256 digest.

The Milestone 1 corpus is a feasibility set, not the final extraction or search
golden set. Later milestones may add narrowly scoped cases from the planning
inventory. A real Google Docs export and any organization-specific evaluation
files remain approved operator inputs; synthetic fixtures must not be described
as production evidence.
