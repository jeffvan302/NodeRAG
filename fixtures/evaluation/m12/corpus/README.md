# Milestone 12 evaluation corpus

This directory contains format projections of approved NodeRag project decisions from `docs/planning`. The content is real project material curated for retrieval evaluation; it is not filler text or a generated relevance benchmark.

The release corpus fixture uses three silos:

- `platform` contains `platform-policy.md` and `project-requirements.docx`.
- `operations` contains `operations-runbook.txt` and `architecture-evidence.pdf`.
- `evaluation` contains `evaluation-matrix.xlsx`.

The PDF includes one raster-only project requirement on page 3 so the vision recovery path can be evaluated. Relevance judgments use stable relative document names plus one-based page numbers or exact sheet names. They never use chunk IDs.

Binary files are generated by `scripts/generate-m12-document-fixtures.py` and `scripts/m12-artifact-runtime/generate-xlsx.mjs`. The committed corpus manifest records their SHA-256 digests.
